How the data gets here

Teensy 4.1 nodeDHT11, LDR and MPU6050 sampled four times a second
→
LoRa radio linkSX1278 at 440 MHz, SF7, 125 kHz, CRC on
→
ESP32 ground stationDecodes each frame and publishes it over Wi-Fi
→
MQTT relayPushed to this page over a secure WebSocket

Frames travel through a public MQTT broker, so treat these readings as a live demonstration rather than calibrated measurements. When the node is powered down the page shows the last frame it received and how long ago that was.
